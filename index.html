Propriedades Position e Display no CSS

Conceito de Display

A propriedade display define se um elemento é tratado como um bloco ou uma linha e o layout usado para seus filhos.

Basicamente ele permite controlar totalmente o posicionamento e o alinhamento de elementos.

As classes de display permitem que você mostre elementos HTML em posições específicas dentro de outros elementos HTML.

Display: Block

O display block gera uma caixa de elemento em bloco.

Comportamento:

Cada elemento se expande horizontalmente e ocupa toda a largura disponível;

Começa sempre em uma linha nova;

Os elementos se empilham verticalmente;

Ele permite definir a largura, altura, margens e preenchimento (padding).

Display: Inline

O elemento gera uma ou mais caixas de elemento em linha que não geram quebras de linha antes ou depois de si mesmas.

Comportamento:

O próximo elemento estará na mesma linha se houver espaço;

As propriedades de altura e largura assim como margem não funcionam;

Ele usa somente o espaço necessário.

Exibe um elemento como um contêiner de bloco em linha.

Comportamento:

Ele permite que os elementos fiquem lado a lado em uma linha (inline);

Display: Flex

Exibe um elemento em um contêiner flexível.

Comportamento:

Ele alinha itens automáticamente em linhas ou colunas;

Ele ocupa toda toda a largura disponível;

Permite alinhar e distribuir os containers filhos.

Display: Inline Flow

Os elementos com inline ficam na mesma linha, lado a lado com outros elementos.

Comportamento:

Eles não aceitam largura (width), nem altura (height), pois o tamanho do elemento é definido pelo conteúdo que possui;

O conteúdo dentro dos elementos segue o fluxo normal do HTML.

Conceito de Position

A propriedade position define como um elemento pode ser posicionado no documento.

Essa propriedade pode ser acompanhada de outras: top, right, bottom e left. Que determinam como ficará a localização final do objeto, permitindo seu deslocamento.

Position: Static

Todos os elementos HTML são posicionados estaticamente por padrão.

Elementos com esse posicionamento não são afetados pelas propriedades superior, inferior, esquerda e direita.

Position: Relative

Um elemento com relative é posicionado em relação à sua posição normal no fluxo do documento.

Definir as propriedades superior, direita, inferior e esquerda fará com que o elemento seja ajustado para fora de sua posição normal.

Position: Absolute

O elemento é posicionado em relação ao ancestral posicionado mais próximo.

No entanto, se um elemento com posicionamento absoluto não tiver ancestrais posicionados, ele usará o corpo do documento e se moverá junto com a rolagem da página.

Nota: Elementos com posicionamento absoluto são removidos do fluxo normal do documento e podem sobrepor-se a outros elementos.

Position: Fixed

O elemento é posicionado em relação à janela de visualização.

Ou seja, ele permanece sempre no mesmo lugar, mesmo se a página for rolada. As propriedades `top`, `right`, `bottom` e `left` são usadas para definir a posição final do elemento.

Um elemento fixo não deixa um espaço em branco na página onde normalmente estaria localizado.

Position: Sticky

Um elemento position: sticky; alterna entre uma posição fixa relative e uma fixed posição variável, dependendo da posição de rolagem.

Um elemento fixo é posicionado de forma relativa até que uma determinada posição de rolagem seja alcançada - então ele "fixa" nesse local (como position:fixed).
