Propriedades Position e Display no CSS

Conceito de Display

A propriedade display define se um elemento é tratado como um bloco ou uma linha e o layout usado para seus filhos.

Basicamente ele permite controlar totalmente o posicionamento e o alinhamento de elementos.

As classes de display permitem que você mostre elementos HTML em posições específicas dentro de outros elementos HTML.

Display: Block

O display block gera uma caixa de elemento em bloco.

Comportamento:

Cada elemento se expande horizontalmente e ocupa toda a largura disponível;

Começa sempre em uma linha nova;

Os elementos se empilham verticalmente;

Ele permite definir a largura, altura, margens e preenchimento (padding).

Display: Inline

O elemento gera uma ou mais caixas de elemento em linha que não geram quebras de linha antes ou depois de si mesmas.

Comportamento:

O próximo elemento estará na mesma linha se houver espaço;

As propriedades de altura e largura assim como margem não funcionam;

Ele usa somente o espaço necessário.

Display: Inline Block

Exibe um elemento como um contêiner de bloco em linha.

Comportamento:

Ele permite que os elementos fiquem lado a lado em uma linha (inline);

É possível aplicar valores de altura e largura (block).

Display: Flex

Exibe um elemento em um contêiner flexível.

Comportamento:

Ele alinha itens automáticamente em linhas ou colunas;

Ele ocupa toda toda a largura disponível;

Permite alinhar e distribuir os containers filhos.

Display: Inline Flow

Os elementos com inline ficam na mesma linha, lado a lado com outros elementos.

Comportamento:

Eles não aceitam largura (width), nem altura (height), pois o tamanho do elemento é definido pelo conteúdo que possui;

O conteúdo dentro dos elementos segue o fluxo normal do HTML.

Display: Inline Flex

Os elementos com inline ficam na mesma linha.

Comportamento:

Permite alinhar e distribuir os elementos filhos automaticamente em linha ou coluna;

Diferente do inline normal, pode usar altura e largura.

Display: Inline Grid

Os elementos com inline ficam na mesma linha.

Comportamento:

Dentro dele é criado um grid container.

Os elementos filhos podem ser organizados em linhas e colunas;

Diferente do inline normal, aceita largura e altura.

Display: Inline flow-root

Os elementos com inline ficam na mesma linha.

Comportamento:

O conteúdo dentro dos elementos segue o fluxo normal do HTML;

Ele cria um novo contexto de layout dentro do elemento;

Evita problema com o float;

Faz com que o elemento pai envolva corretamente os elementos filhos.
