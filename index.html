Propriedades Position e Display no CSS

Conceito de Display

A propriedade display define se um elemento é tratado como um bloco ou uma linha e o layout usado para seus filhos.

Basicamente ele permite controlar totalmente o posicionamento e o alinhamento de elementos.

As classes de display permitem que você mostre elementos HTML em posições específicas dentro de outros elementos HTML.

Display: Block

O display block gera uma caixa de elemento em bloco.

Comportamento:

Cada elemento se expande horizontalmente e ocupa toda a largura disponível;

Começa sempre em uma linha nova;

Os elementos se empilham verticalmente;

Ele permite definir a largura, altura, margens e preenchimento (padding).
